# FastAPI Auth

> Plug-and-play authentication for FastAPI. Configure it, mount it, and start protecting your API in minutes.

FastAPI Auth is a Python package that helps developers add authentication to their FastAPI applications with minimal setup. Instead of building authentication from scratch, you configure the package, plug it into your app, and get production-ready auth endpoints, middleware, and utilities out of the box.

Whether you're building an MVP, an internal tool, or your next SaaS, FastAPI Auth lets you spend less time wiring up authentication and more time building your product.

## ✨ Features

* 🚀 Quick setup with sensible defaults
* 🔐 Secure authentication flows
* ⚙️ Configuration-first approach
* 🛡️ Route protection made simple
* 📦 Easy integration with existing FastAPI projects
* 🧩 Extensible architecture for custom auth logic
* 📚 Clean, developer-friendly API

## 🚧 Status

FastAPI Auth is currently under active development. APIs may evolve before the first stable release, but the goal remains the same:

> Authentication that feels like part of FastAPI—not an entire project of its own.

## Getting Started

Installation, configuration, and usage guides are available in the documentation.

```bash
pip install fastapi-auth
```

Then configure the package, mount it into your FastAPI application, and you're ready to start protecting your endpoints.

## Philosophy

Authentication should be easy to add, hard to get wrong, and flexible enough to fit your application—not the other way around.

FastAPI Auth aims to provide the right balance between convention and customisation, giving you sensible defaults while allowing you to override behaviour whenever your project demands it.
